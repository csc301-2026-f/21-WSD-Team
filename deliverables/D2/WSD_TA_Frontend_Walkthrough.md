# Wise Storage Director (WSD) — Frontend Grading Walkthrough

This guide is for TAs reviewing the **frontend features** of WSD. Use the **☰ menu** to switch between views. The example values in the screenshots are illustrative; actual numbers depend on the computer's current disk activity.

## 1. Disk Recognition — Main Page

1. Open **Main Page**.
2. Check that each card shows the **drive name/model**, a **storage usage bar**, and the **percentage of capacity used**.

![Drive model with their capacity](./frontend_pictures/DriveInfo.png)

## 2. Storage Recommendations

Swipe down on the main page to inspect advisory suggestions, including the reason, source/target device, and constraints. The example shown uses **mock data**. Recommendations **do not automatically move files**; this screen is separate from the monitoring views covered in this guide.

![Recommendation Generated by algorithm with mock input](./frontend_pictures/recommendation.png)

## 3. Disk Real-Time I/O — Storage Performance

1. Click on ≡ sign on top left and choose Disk Usage Statistics
2. Observe **Total, Read, and Write Throughput (MB/s)** and **Total, Read, and Write IOPS**.
3. Check **Devices Reporting** and **Last Updated** to confirm the source count and that the readings update.
4. Perform a disk read or write (such as copying a file), then observe the corresponding activity on this page.

![Real time disk stats](./frontend_pictures/RealTimeIOStats.png)

## 4. Disk Historical Average I/O — Disk Usage Over Time

1. View the two historical graphs:
   - **Average Throughput (MB/s):** read and write transfer rates over time.
   - **Average IOPS:** read and write operations per second over time.

![Historical disk stats](./frontend_pictures/DiskUsageHistory.png)

## 5. Process Real-Time I/O — Application I/O

1. On **Disk Usage Statistics**, scroll past **Process I/O History** to the **Application I/O** table.
2. Find a running application by its name and **PID** (process ID).
3. Generate disk activity in that application and check that its **Read Rate** and **Write Rate** update.
4. **Unattributed** means the reading is not assigned to a specific disk.

![Real-time process read and write rates](./frontend_pictures/RealTimeProcessIO.png)

## 6. Process Historical I/O — Process I/O History

1. Scroll back up to **Process I/O History**.
2. Choose an application from **Select application**.
3. Check its read and write throughput over time in the chart. Allow samples to accumulate if it has just started collecting.

![Selected application's read and write history](./frontend_pictures/SelectProcessIOHistory.png)
