WSD Project Info

General Breakdown

Many PCs contain a mix of fast and slow storage. Users must manually decide where applications and files should live, often without knowing which data actually needs the faster drive. Changing those decisions later can be inconvenient.

WSD monitors storage activity at the application and file level, identifies which data benefits most from faster storage, and recommends where that data should be placed. With the user's approval, WSD can then apply the recommended changes.
