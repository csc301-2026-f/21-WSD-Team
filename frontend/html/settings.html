Implementation details

File-level pooling

WSD includes RAID 0 placement recommendation logic. The backend does not integrate mergerfs or expose pool mount configuration, so a unified pool is not currently provided.

SSD caching

A caching selection helper exists in the algorithm code, but cache routing, coherency, and execution are not implemented or wired into the active API.
