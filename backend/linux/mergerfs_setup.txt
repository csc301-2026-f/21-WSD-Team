This is a documentation on how to setup mergerfs so it will work on linux with WSD.

NOTE: IMPORTANT!!!
When you are going to approve a suggestion made by the algorithm, make sure all file in that suggestion is closed
or at least nothing is writing to it. When using raid-0 mode, the source file will be deleted on HDD and any write
to the source file will be lost after you initiate the move.

When setting up mergerfs, use the following setting
HDD(replace with your HDD mount directory)=RW
SSD(replace with your SSD mount directory)=RW
category.create=ff
func.mkdir=all
moveonenospc=false

remember to put HDD mount point before SSD

This will make create matching directory on both drives, and only put the file on HDD (when it has space)
If HDD runs out of space, new file will be again placed on SSD (or another HDD)
