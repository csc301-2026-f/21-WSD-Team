Using an existing mergerfs pool with WSD

For Linux RAID0 recommendations, CORE expects exactly one mounted mergerfs
pool. Configure the HDD and SSD branch mount paths as writable (=RW), with the
HDD first. Use these mergerfs options for the WSD layout:

    category.create=ff
    func.mkdir=all
    moveonenospc=false

With this order, new files go to the first eligible branch, usually the HDD.
Directory creation uses all eligible branches. Check existing directories on
the destination before moving a file.

In File I/O Monitoring, select a file through its pool path and enter the
destination branch mount. For example, /srv/pool/docs/a.md and /mnt/ssd
resolve to a destination of /mnt/ssd/docs/a.md. Confirm that /mnt/ssd is a
writable branch of this pool, /mnt/ssd/docs exists, the target file is absent,
and the branch has room for the file. Close writers before confirming.
A successful move removes the source branch copy and preserves the pool path.
